# Pesquisa de Atendimento ao Cliente

Programa em Python desenvolvido para coletar e analisar o retorno de uma pesquisa de atendimento ao cliente, cumprindo os requisitos de uma atividade de desenvolvimento de sistemas.

## 📋 Funcionalidades
- Solicita o nome, a idade e a avaliação de 50 entrevistados.
- Utiliza estrutura de repetição (`for`) para a coleta dos dados.
- Utiliza estrutura de decisão (`if/elif/else`) para classificar as respostas:
  - **1:** Excelente
  - **2:** Bom
  - **3:** Ruim
- Exibe o consolidado com a quantidade total de respostas "Excelente", "Bom" e "Ruim" ao final das entrevistas.
